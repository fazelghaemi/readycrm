# 🚀 سیستم مدیریت ارتباط با مشتری (CRM) - نسخه حرفه‌ای

## 📋 معرفی پروژه

این یک سیستم کامل و حرفه‌ای مدیریت مشتریان (CRM) است که برای کسب‌وکارهای کوچک و متوسط طراحی شده. سیستم شامل تمام امکانات مورد نیاز برای مدیریت مشتریان، فروش، محصولات و گزارش‌گیری است.

## ✨ ویژگی‌های کلیدی

### 🎯 **مدیریت مشتریان**

- ثبت و مدیریت اطلاعات کامل مشتریان
- تاریخچه خرید و تعاملات
- جستجو و فیلتر پیشرفته
- دسته‌بندی مشتریان (فردی/شرکتی)
- مدیریت آدرس و اطلاعات تماس

### 💰 **مدیریت فروش**

- ثبت سفارشات و فاکتور
- محاسبه خودکار مالیات و تخفیف
- پیگیری وضعیت پرداخت
- گزارش‌گیری فروش
- مدیریت روش‌های پرداخت

### 📦 **مدیریت محصولات**

- ثبت محصولات و خدمات
- کنترل موجودی و انبار
- دسته‌بندی محصولات
- مدیریت قیمت‌ها
- بارکد و SKU

### 🎯 **مدیریت لیدها**

- ثبت فرصت‌های فروش
- پیگیری مراحل فروش
- اولویت‌بندی لیدها
- تبدیل لید به مشتری
- گزارش‌گیری فروش

### ✅ **مدیریت وظایف**

- ایجاد و تخصیص وظایف
- پیگیری پیشرفت کارها
- یادآوری و اعلان‌ها
- گزارش‌گیری عملکرد
- مدیریت تیم

### 📊 **گزارش‌گیری و آمار**

- داشبورد تعاملی
- نمودارهای فروش
- آمار مشتریان
- گزارش‌های مالی
- تحلیل عملکرد

### 👥 **مدیریت کاربران**

- سیستم نقش‌ها و مجوزها
- مدیریت دسترسی‌ها
- ثبت فعالیت‌ها
- امنیت پیشرفته

## 🛠️ فناوری‌های استفاده شده

- **Backend**: PHP 8.0+
- **Database**: MySQL 5.7+
- **Frontend**: HTML5, CSS3, JavaScript
- **Framework**: Bootstrap 5.3
- **Icons**: Font Awesome 6.4
- **Charts**: Chart.js 3.9
- **Security**: PDO, Password Hashing, CSRF Protection

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

- PHP نسخه 8.0 یا بالاتر
- MySQL نسخه 5.7 یا بالاتر
- وب سرور (Apache یا Nginx)
- Extension های PHP: PDO, OpenSSL, JSON

### مرحله 1: دانلود و کپی فایل‌ها

```bash
# کپی فایل‌ها در پوشه htdocs
cp -r new-crm /Applications/XAMPP/xamppfiles/htdocs/
```

### مرحله 2: تنظیم دیتابیس

1. دیتابیس جدید ایجاد کنید:

```sql
CREATE DATABASE crm_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. فایل schema را import کنید:

```bash
mysql -u root -p crm_system < database/schema.sql
```

### مرحله 3: تنظیمات

فایل `private/config.php` را ویرایش کنید:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'crm_system');
define('DB_USER', 'نام_کاربری_دیتابیس');
define('DB_PASS', 'رمز_عبور_دیتابیس');
define('BASE_URL', 'http://localhost/new-crm/');
```

### مرحله 4: مجوزهای فایل

```bash
chmod 755 /Applications/XAMPP/xamppfiles/htdocs/new-crm/
chmod 777 /Applications/XAMPP/xamppfiles/htdocs/new-crm/uploads/
chmod 777 /Applications/XAMPP/xamppfiles/htdocs/new-crm/logs/
```

### مرحله 5: ورود به سیستم

- آدرس: `http://localhost/new-crm/`
- نام کاربری: `admin`
- رمز عبور: `password`

## 👤 کاربران پیش‌فرض

| نام کاربری | رمز عبور   | نقش   | دسترسی                |
| ---------- | ---------- | ----- | --------------------- |
| `admin`    | `password` | ادمین | دسترسی کامل           |
| `manager`  | `password` | مدیر  | مدیریت و گزارش‌گیری   |
| `sales1`   | `password` | فروش  | مدیریت فروش و مشتریان |
| `user1`    | `password` | کاربر | مشاهده محدود          |

**⚠️ نکته امنیتی**: حتماً بعد از ورود اولیه رمز عبورها را تغییر دهید!

## 🔧 تنظیمات پیشرفته

### تغییر نام شرکت

در فایل `private/config.php`:

```php
define('APP_NAME', 'نام شرکت شما');
define('COMPANY_NAME', 'نام شرکت');
define('COMPANY_ADDRESS', 'آدرس شرکت');
define('COMPANY_PHONE', 'شماره تماس');
define('COMPANY_EMAIL', 'ایمیل شرکت');
```

### تغییر رنگ‌ها و تم

در فایل `private/header.php` بخش CSS:

```css
:root {
  --primary-color: #ff6b35; /* رنگ اصلی */
  --primary-dark: #e55a2b; /* رنگ تیره */
  --success-color: #10b981; /* رنگ موفقیت */
  --warning-color: #f59e0b; /* رنگ هشدار */
  --danger-color: #ef4444; /* رنگ خطا */
}
```

### اضافه کردن لوگو

1. لوگوی خود را در پوشه `assets/` قرار دهید
2. در فایل `private/header.php` مسیر را تغییر دهید:

```html
<img src="assets/logo.png" alt="لوگو" class="logo" />
```

## 🚨 عیب‌یابی

### مشکلات رایج

#### خطای اتصال به دیتابیس

```bash
# بررسی وضعیت MySQL
sudo service mysql status

# راه‌اندازی MySQL
sudo service mysql start

# بررسی تنظیمات
cat private/config.php
```

#### صفحه سفید

```bash
# فعال کردن نمایش خطاها
# در فایل private/config.php:
ini_set('display_errors', 1);
error_reporting(E_ALL);

# بررسی لاگ خطاها
tail -f logs/error.log
```

#### مشکل در آپلود فایل

```bash
# بررسی مجوزهای پوشه
ls -la uploads/

# تنظیم مجوزها
chmod 777 uploads/
```

#### مشکل در لاگین

1. بررسی اطلاعات دیتابیس
2. پاک کردن کوکی‌های مرورگر
3. بررسی تنظیمات session

### لاگ‌ها و دیباگ

- **لاگ خطاها**: `logs/error.log`
- **لاگ فعالیت‌ها**: جدول `activity_logs` در دیتابیس
- **لاگ Apache**: `/Applications/XAMPP/xamppfiles/logs/error_log`
