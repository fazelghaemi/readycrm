# سیستم مدیریت مشتریان (CRM) - نسخه فروش

## 📋 معرفی پروژه

این یک سیستم کامل مدیریت مشتریان (CRM) است که برای فروش آماده شده. سیستم شامل تمام امکانات مورد نیاز یک کسب‌وکار کوچک و متوسط است.

## ✨ چه کاری انجام می‌دهد؟

- **مشتریان**: ثبت و مدیریت اطلاعات مشتریان
- **فروش**: ثبت سفارشات و فاکتور
- **محصولات**: مدیریت موجودی کالا
- **لیدها**: پیگیری مشتریان احتمالی
- **وظایف**: مدیریت کارهای تیم
- **گزارشات**: آمار و نمودارهای فروش
- **کاربران**: مدیریت دسترسی کارمندان

## 🚀 نصب و راه‌اندازی

### مرحله 1: آماده‌سازی سرور
```
- PHP نسخه 8.0 یا بالاتر
- MySQL نسخه 5.7 یا بالاتر
- وب سرور (Apache یا Nginx)
```

### مرحله 2: کپی فایل‌ها
1. تمام فایل‌ها را در پوشه `htdocs` کپی کنید
2. مطمئن شوید که پوشه `config` و `database` موجود است

### مرحله 3: نصب خودکار
1. در مرورگر به آدرس زیر بروید:
   ```
   http://localhost/نام_پوشه_پروژه/install.php
   ```
2. مراحل نصب را دنبال کنید:
   - اطلاعات دیتابیس را وارد کنید
   - نام کاربری و رمز عبور ادمین را تعیین کنید (اختیاری)
   - روی "نصب" کلیک کنید

### مرحله 4: ورود به سیستم
1. به آدرس اصلی پروژه بروید
2. با یکی از کاربران پیش‌فرض وارد شوید:
   - **ادمین**: `admin` / `password`
   - **مدیر**: `manager` / `password`
   - **فروش**: `sales1` / `password`
   - **کاربر**: `user1` / `password`

## 🗄️ راه‌اندازی دیتابیس

### روش 1: نصب خودکار (توصیه شده)
سیستم خودش دیتابیس را می‌سازد و جداول را ایجاد می‌کند.

### روش 2: دستی
اگر نصب خودکار کار نکرد:

1. دیتابیس جدید بسازید:
```sql
CREATE DATABASE crm_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. فایل `database/schema.sql` را import کنید

3. فایل `config/config.php` را ویرایش کنید:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'crm_system');
define('DB_USER', 'نام_کاربری_دیتابیس');
define('DB_PASS', 'رمز_عبور_دیتابیس');
```

## 📊 رکوردهای تستی

بعد از نصب، سیستم شامل این داده‌های نمونه است:

### 👤 **کاربران پیش‌فرض**
سیستم با 4 کاربر از پیش ساخته شده نصب می‌شود:

| نام کاربری | رمز عبور | نقش | نام کامل |
|------------|-----------|------|----------|
| `admin` | `password` | ادمین | علی احمدی |
| `manager` | `password` | مدیر | سارا محمدی |
| `sales1` | `password` | فروش | رضا کریمی |
| `user1` | `password` | کاربر | مریم حسینی |

**⚠️ نکته مهم**: رمز عبور پیش‌فرض برای همه کاربران `password` است. حتماً بعد از ورود اولیه آن‌ها را تغییر دهید!

### 📋 **داده‌های نمونه**
- **مشتریان**: 5 مشتری با اطلاعات کامل
- **محصولات**: 10 محصول مختلف  
- **فروش**: 10 سفارش برای تست
- **لیدها**: 10 فرصت فروش مختلف
- **وظایف**: 10 کار مختلف
- **گزارشات**: آمار کامل برای نمایش
